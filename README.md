# PandaAI 数据套餐 · 本地预览

来源：https://www.pandaaiquant.com/data-service

## 打开

双击 `start-preview.cmd`，或在此目录运行 `node server.mjs`，访问 http://127.0.0.1:4174/data-service#plans-title 。页面依赖 ES 模块与本地 JSON，请通过 HTTP 预览打开。

## 当前数据套餐界面

- 左侧为“基础底座”和“场景模块”两个一级分类，分别使用灰色和黑色卡片。
- 左侧分类卡片采用两列结构：左侧大面积流动背景承载标题、说明与起始算力，右侧为内容清单和底部分类开关。
- 右侧每个模块使用独立白色面板，内部为对应上级的灰色或黑色有色标题条；编号只保留 01、02 等数字，内容直接完整展示。
- 模块详情字号统一缩小一级；模块面板内不再显示“订购此模块”按钮，各模块保持独立展示，不在此处累计。
- 右侧详情内容采用横向优先的自动换行排列，同层级项目会尽量在一行展示，宽度不足时再换到下一行。
- 模块彩色标题条中的说明文字解除窄宽限制，同层级内容优先保持一行，窄屏按实际空间自然折行。
- 每个模块详情保留真实接口名称与说明，单独权限卡片的“立即订阅”按钮将该权限带入原订购弹窗。A 股进阶与期货深度模块仍由弹窗补齐必需底座。
- 左侧底部改为白色圆角横条，文案调整为“需要组合报价？进入弹窗后再选择订阅周期、基础底座和场景模块。”；带黑色圆箭头的“自由搭配订购”按钮可打开原完整组合订购弹窗，悬停、聚焦和点击时黑色背景从左向右铺满按钮。
- 灰黑背景使用柔和模糊的 SVG 轮廓持续变形，配合光影缓慢流动；各卡片错开循环，不跟随鼠标，也没有旋转矩形造成的硬边界。系统减少动态效果设置下保持静止，已按要求删除暂停图标。
- 切换分类时，旧文案先淡出，背景过渡后新文案向上显现；切换结束后所有文案恢复完整显示。
- 右侧全部模块的数据内容统一为简洁文字排列，移除逐行勾选、信息图标及分隔线，仍可点击文字查看真实接口说明。标题、说明及列表的字间距已放宽。
- 图层和箭头使用统一线宽的内嵌 SVG 图标。
- 桌面左右排列，平板和手机上下排列。右侧模块自然铺开，不设共用滚动框。

## 单独权限服务界面

- 单独权限服务保留六个一级分类：A股、期货、港美股、宏观、基金、量化。左侧参考横向白色圆角卡片，采用“纯流动方形色块 / 分类文案 / 内容清单”三段式排版；色块上不放文字、数字或图标。
- 分类名称、说明、适用场景与起始算力均放在白色区域；起始算力取该分类真实最低年费。右侧呈现权限数量、三项简短清单和底部开关，当前分类由开关状态表达。
- 桌面卡片保持三列，手机端切换为色块与文案并排、清单和开关置于下方。两个服务板块的整体左右比例保持一致。
- 已完整恢复到 2026-11-10 调整分类颜色之前的版本：左右内容随页面自然滚动，不添加独立滚动容器、吸顶、滚轮拦截或分类切换后的自动滚动复位。
- 两个服务共用同一切换动画：旧文字淡出上移，新内容渐显并向上展开，背景同步过渡；流动背景持续自主变形，不跟随鼠标。
- 六个权限分类依次采用浅灰到黑色的六级配色，右侧权限卡片使用当前分类对应的颜色；浅色背景采用深色文字。保留回退版本的 SVG 轮廓变形、逐项文字切换和自然页面滚动。
- 单独权限区已删除顶部“30 项权限”标签，并与数据套餐服务统一左右比例、列间距和顶部对齐；右侧按分类展示独立权限卡片，保留编号、数据项、灰黑流动背景、算力价格、问号接口图标和立即订阅入口。
- 指数分钟数据归入 A 股分类，六类共覆盖 30 项权限；分类切换使用旧内容淡出、新内容渐显的文字动效。
- 单独权限订阅仍调用原订购弹窗，接口说明继续使用真实 API 浮层；订阅按钮悬停时沿用黑色铺满动效。

主要修改文件：`plan-configurator.js`、`plan-configurator.css`、`permission-configurator.js`、`permission-configurator.css`、`service-overview.css`、`_nuxt/Dr8sB5Gz.js`、`_nuxt/D_TFGXye.js`。

## 保留内容

原站字体、首屏动画、卡片堆叠、订购弹窗、2 个基础底座、7 个场景模块、30 项单独权限、分类筛选、真实接口浮层、包季/包年切换、账户等级说明及订阅确认弹窗均保留。API 文档链接指向原站。

`catalog.json` 为目录快照，`package-api.json` 为接口说明，`local-preview.js` 将目录和报价请求适配到本地。报价按公开年费和 T0 原价展示，包季按年费四分之一向下取整。未保存登录凭证、历史消费、余额或个性化等级折扣。最终确认只显示本地提示，不创建订单、不扣费。
